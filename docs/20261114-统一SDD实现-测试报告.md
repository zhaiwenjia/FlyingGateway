## 六、已知边界与后续项（如实登记）

1. **SDK 序列化合法差异**（行为语义等价，wire 非逐字节）：空 `messages` 整键省略（原发 `null`）、SDK 自带请求头（`User-Agent: Anthropic/Go`、`X-Stainless-*`）、JSON 键序字母序化、gemini `functionCall.args` 键序规范化、`float32` 精度截断（temperature/topP 高精度小数）。
2. **Anthropic 帧转换双实现**：Claude 走 SDK typed、MiniMax Anthropic 形走手写解析（复用共享符号）——语义各由测试钉住，改一处须同步另一处。
3. **Gemini 适配器为 Tier 2**（typed 构造/解析 + 既有 HTTP 执行）：genai 流解析与执行耦合不可单用、错误体/usage 原文在 SDK 内丢失（Tier 1 会破行为红线）。
4. **fixture 缺口**（登记表附检索记录）：Grok Chat 形 raw usage JSON、OpenAI 官方直连 Chat 形、7 家完整逐帧真实流记录、Ollama /v1 usage——搜不到的如实留空，⛔ 未以合成顶替。
5. qwen 流式「data 无 type 回落 `event:` 行」容错因 SDK 流不暴露 event 行而不保留。
6. 费用落结构化日志（Response 无 cost 槽位）；费率 md→json 生成脚本（对账由单测承担）——后续项。
